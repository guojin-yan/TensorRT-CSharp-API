# TensorRT-CSharp-API 4.0.0.1

发布日期：2026-09-10

版本类型：托管包维护迭代

`4.0.0.1` 是 `4.0.0` 正式版之后的 C# 核心托管包小版本迭代。该版本用于交付当前源码中的托管核心变更，同时保留 `4.0.0` 的既有包和运行时组合，降低升级对现有使用者的影响。

## 主要变更

- 发布 `JYPPX.TensorRT.CSharp.API` 托管包 `4.0.0.1`。
- 版本解析与工作流支持 `4.0.x.y` 形式的小版本号。
- 不改变公开命名空间、Bridge 包矩阵或 NVIDIA 运行库安装边界。

## 发布物

本次迭代只包含一个托管包：

- `JYPPX.TensorRT.CSharp.API`：`4.0.0.1`

项目自有 `.Bridge` 包继续保持 `4.0.0`，不随本次托管包维护迭代重新发布。CUDA、cuDNN、TensorRT 和 NVRTC 仍由使用者自行安装。

## 兼容性与升级

- 已使用 `4.0.0` 的项目可以继续保持原版本，不需要同步升级 Bridge 包。
- 需要当前 C# 核心修订的项目，将托管包升级到 `4.0.0.1`，Bridge 包仍按目标机器的运行时矩阵使用 `4.0.0`。
- 本版本不承诺新的原生运行时能力；引擎、驱动和 NVIDIA 运行库兼容性要求与 `4.0.0` 相同。

## 验证范围

- `JYPPX.TensorRT.CSharp.API.4.0.0.1.nupkg` 已完成 Release 打包。
- 托管包内容校验通过，包内不包含 CUDA、cuDNN、TensorRT、NVRTC 或其它第三方原生运行库。
- 发布前仍需在目标环境完成真实 GPU runtime 验证；本次版本号迭代不把构建验证扩大为全矩阵运行时证明。
