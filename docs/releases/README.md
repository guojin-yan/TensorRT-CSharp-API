# 版本说明

本目录保存 TensorRtSharp4.0 每个公开版本的详细更新说明。根目录中英文 README 只展示当前版本摘要；这里的总表负责汇总所有版本，并链接到各版本的完整说明。

| 版本 | 日期 | 类型 | 说明 |
| --- | --- | --- | --- |
| [4.0.0-preview.1](4.0.0-preview.1.md) | 2026-08-06 | Preview | 首个 4.0 公开预览版，建立托管 API、bridge-only 包矩阵、示例与发布约束。 |

## 维护规则

每次版本迭代都必须同时完成以下更新：

1. 在本目录新增以完整 SemVer 命名的详细说明文件，例如 `4.0.0-preview.2.md`。
2. 在本总表顶部加入版本、日期、类型和说明链接。
3. 更新根目录 `README.md` 与 `README.zh-CN.md` 的“本次更新”摘要和链接。
4. 详细说明至少包含主要变更、发布物、兼容性与环境要求、升级注意、验证范围和已知限制。
5. 说明必须区分源码/构建验证、真实运行时验证和公开包验证，不得把未执行或受环境阻塞的项目写成已通过。

版本说明只记录项目自有源码与发布物。模型权重、ONNX 模型及 NVIDIA 厂商运行库不进入 Git 仓库或 NuGet 包。
