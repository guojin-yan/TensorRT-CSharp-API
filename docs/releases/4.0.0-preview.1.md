# TensorRtSharp4.0 4.0.0-preview.1

发布日期：2026-08-06  
版本类型：首个公开预览版

`4.0.0-preview.1` 固定 TensorRtSharp4.0 的第一套公开托管 API、项目自有原生桥接包和发布边界。本版本优先保证核心推理、CUDA 基础能力、包引用和主要示例流程可用；尚未完成的硬件或 TensorRT 版本组合将在后续预览版持续验证。

## 主要变更

- 顶层命名空间统一为 `JYPPX.TensorRtSharp` 与 `JYPPX.CudaSharp`，未单独归类的 TensorRT 共享能力归入 `JYPPX.TensorRtSharp`。
- `src` 下的 C# 接口按 TensorRT、CUDA、运行时、显存、诊断和工具等模块整理，保留现有公开接口兼容性。
- 覆盖 engine 构建与加载、execution context、tensor/binding、动态 shape、日志、profiling、allocator、stream/event、CUDA Graph 和 CUDA RTC 等核心路径。
- 提供 TensorRtExec 桌面工具，以及分类、检测、分割、姿态、OBB、语义分割和 ONNX-to-engine 等源码示例。
- 演示模型统一记录官方来源、固定版本、许可证、获取方式、转换命令、输入输出契约和 SHA256；转换后的 ONNX 暂存于仓库外层 `models` 目录，不上传 GitHub。
- NuGet 包使用 Apache-2.0 许可证、`nuget/logo.jpg` 图标和根目录英文 README。

## 发布物

本版的公开发布物范围限定为：

- `JYPPX.TensorRT.CSharp.API` 托管 NuGet 包；
- Windows 与 Linux 的版本化 `.Bridge` NuGet 包；
- GitHub Release 中的源码归档、托管包和 bridge-only 包。

`applications/YoloVision`、`samples/ComputerVision/01.Classification` 等示例项目不作为 NuGet 包发布。Bridge 包只包含项目编译的 `jyppxtrtbridge.dll` 或 `libjyppxtrtbridge.so`，不包含 CUDA、cuDNN、TensorRT 或 NVRTC 厂商运行库。

## 兼容性与环境要求

- 使用者必须安装与所选 Bridge 包名一致的 CUDA、cuDNN 和 TensorRT 版本，并安装兼容的 NVIDIA 驱动。
- Windows 与 Linux Bridge 包按 RID、TensorRT、CUDA、cuDNN 版本分别命名，不能跨 TensorRT 主版本混用。
- 托管 API 面向项目声明的 .NET Framework、.NET Core 与现代 .NET 目标；实际运行能力仍取决于目标框架、操作系统和 NVIDIA 环境。
- 模型、engine 与运行日志默认保存在 Git 仓库外；TensorRT engine 与构建它的 TensorRT/GPU 环境具有兼容性边界。

## 升级注意

这是 4.0 系列的首个公开版本，没有从先前 4.0 公共包升级的迁移步骤。由开发快照迁移时，应检查命名空间是否已归入 `JYPPX.TensorRtSharp` 或 `JYPPX.CudaSharp`，并将旧的全运行库依赖包替换为匹配环境的 `.Bridge` 包。

不要把 CUDA、cuDNN、TensorRT DLL/SO 复制进应用包来绕过版本匹配。部署时应通过系统安装位置、`PATH`/动态链接器路径以及项目环境探测确认依赖。

## 验证范围与已知限制

- Release 配置的托管解决方案、绑定生成、发布合同测试、包内容策略和文档构建纳入首版门禁。
- 主要真实模型流程保留输入、输出、预处理、哈希和数值比较证据；没有兼容本机硬件/驱动的路径会明确标记为环境阻塞，不伪装成通过。
- 首个预览版不宣称 TensorRT 8/10/11 在所有 Windows/Linux、CUDA、cuDNN、GPU 组合上完成完整接口测试。
- 示例结果与技术文章将继续补充真实程序输出截图、GUI 页面截图和绘制后的视觉结果；缺少真实截图的内容不能作为完整发布文章。
- 模型权重与 ONNX 不进入本仓库，后续计划迁移到独立 ModelZoo。

完整包矩阵、安装入口和当前发布状态见 GitHub 上的 [英文 README](https://github.com/guojin-yan/TensorRT-CSharp-API/blob/TensorRtSharp4.0/README.md) 或 [中文 README](https://github.com/guojin-yan/TensorRT-CSharp-API/blob/TensorRtSharp4.0/README.zh-CN.md)。
