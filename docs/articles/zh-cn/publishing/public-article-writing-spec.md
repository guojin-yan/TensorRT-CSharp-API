# 中文公开文章写作与发布规范

本规范约束 `article-index.json` 中登记的全部中文公开文章。规范文章尚未发布时可以修订；状态进入 `published` 后，正文、发布提交和正文哈希必须冻结，后续更正通过勘误或 `supersedes` 关系完成。

## 1. 标题与层级

1. 一级标题是文章标题，不编号；标题中的项目品牌统一写为 `TensorRT CSharp API v4.0`，不得省略 `CSharp` 和 `API` 之间的空格，也不得出现 `TensorRtSharp4.0`。
2. 正文从二级标题开始编号，格式为 `1.`、`2.`；三级和四级标题分别使用 `1.1`、`1.1.1`。
3. 每篇文章必须从“前言”开始。前言除说明本文问题外，还要完整介绍项目定位、核心包、Runtime Bridge、源码入口和本文程序入口。
4. 不在文章末尾放置“下一篇”链接。尚未发布的后续内容只能写入模块规划，不得伪装成已经可访问的文章入口。

## 2. 链接兼容性

公开平台对 Markdown 链接的支持不一致，因此正文不得只保留 `[名称](网址)` 这种隐藏目标地址的写法。

- 每篇文章前言中的项目主页、核心 NuGet、Runtime Bridge 包列表、运行库清单必须分别使用“说明文字 + 独立 `text` 代码块”，不得把四个 URL 合并到同一个代码块。
- Runtime Bridge 包列表统一使用 NuGet 搜索页：`https://www.nuget.org/packages?q=+JYPPX.TensorRT.CSharp&includeComputedFrameworks=true&prerel=true&sortby=relevance`。
- 正文中的其他重要入口优先使用说明文字加 `text` 代码块，完整显示 URL。
- 表格使用“网址名称：完整网址”的可见形式，例如 `项目源码：https://github.com/...`。
- 本地 DocFX 导航可以保留相对 Markdown 链接，但程序源码、NuGet 包、厂商工具和外部资料必须同时保留可见的完整 URL。

## 3. 程序、源码与输出

1. 凡文章使用示例、应用、命令行工具或辅助程序，必须标明程序名称、仓库、源码目录或入口文件的完整 URL。
2. 每个可执行流程必须给出输出。可以是经验证的终端输出、报告片段、结果图片或明确标注的期望输出；不得只有命令而没有判定标准。
3. 厂商工具应注明官方来源；仓库内工具应注明本仓库源码位置。
4. 未在兼容环境完成真实运行时，输出必须标注为“期望输出”或“静态检查结果”，不得写成运行通过。

## 4. 图片与流程图

1. 文章正文图片的显示宽度上限为 `640px`，同时设置 `max-width: 100%` 和自动高度。
2. Mermaid 流程图优先使用 `flowchart TD` 的纵向结构；节点文字保持简短，避免公众号页面横向滚动。
3. 超宽截图应裁切到当前步骤需要的区域，或拆成多张图；不能依赖读者横向缩放查看关键文字。
4. 在 `390px` 窄屏下，文章页面本身不得产生横向滚动；长网址和行内代码必须换行，宽代码块与表格只能在各自区域内横向滚动。

## 5. 模块边界

| 模块 | 内容边界 |
| --- | --- |
| `01-release` | 正式发布、版本升级和兼容边界 |
| `02-samples` | 小型、可复现的单功能案例 |
| `03-applications` | 完整工具和业务应用工作流 |
| `04-api` | 按 TensorRT/CUDA 类、对象职责和功能划分的接口用法 |
| `05-installation` | 按平台安装、包选择、运行库矩阵和安装排错 |
| `06-source-build` | 本地源码构建、生成绑定、CMake preset、打包和构建排错 |
| `07-misc` | 项目总览、设计背景、模型资产等跨模块主题 |

## 6. 文章声明

每篇规范文章末尾必须包含统一“文章声明”，完整覆盖开源协议、AI 辅助开发与质量、安全性、技术局限、测试范围、免责声明、开源范围和社区反馈，并引用仓库中的作者联系图。声明之后不得再追加“下一篇”或未发布文章链接。

## 7. 自动校验

提交前运行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\eng\Test-PublicArticleIndex.ps1
dotnet docfx .\docs\docfx.json
```

校验至少检查：规范标题、编号层级、可见外链、项目与 NuGet 入口、程序源码和输出、图片宽度、纵向流程图、统一声明、无下一篇链接，以及本地链接和图片是否存在。
